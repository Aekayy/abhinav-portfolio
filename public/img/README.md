# Images

All present. Pulled from the Framer CDN (framerusercontent.com) on Aug 19,
2026; the source-asset map lives in `newportfolio.md` under "Image manifest".

Layout:

- `about/` — the two portraits on the About page
- `people/` — testimonial photos (Tyi Moncrieffe, Laurence McRory)
- `resume/` — the ATS resume as page images; the PDF itself is
  `public/resume.pdf`, linked from the Resume page
- `home/` — the outdoor portrait (not currently placed; the reference allows
  no decorative imagery on the home page)
- `contact/` — the Framer contact illustration (unused; same reason)
- `work/` — company logos for the work history, project card thumbnails, and
  one folder of case-study figures per project (`merkle/`, `vesseli/`,
  `forecash/`)
- `harmoney/` — the Harmoney study's figures, including the three the study
  text references directly
- `blog/` — post heroes, in-body images and index cards

Figures were fetched at `?scale-down-to=2048`, thumbnails and avatars at 1024
or 512. To replace one, overwrite the file — no code change needed.
